# 🛡️ Adaptive Cyber Threat Detection using Behaviour Modeling

## 🚀 Overview
This project focuses on detecting cyber threats by analyzing system/network behavior and adapting dynamically to new patterns.

Instead of relying only on static rules or signatures, the system uses **behaviour modeling** to identify anomalies and detect potential attacks in real time.

---

## 🎯 Objectives
- Detect cyber threats using behavioral patterns  
- Build an adaptive system that learns from data  
- Identify anomalies in network/system activity  
- Improve detection accuracy over traditional methods  

---

## 🧠 Key Concepts

### 🔹 Behaviour Modeling
Behaviour modeling involves analyzing normal patterns of system or user activity and detecting deviations.

Example:
- Normal traffic vs unusual spike in requests  
- Regular login vs suspicious login attempts  

### 🔹 Adaptive System
An adaptive system improves over time by adjusting to new data and attack patterns.

Example:
- Learning new attack behavior  
- Updating detection rules dynamically  

---

## 📁 Dataset
The dataset contains features related to network/system activity such as:
- Packet size  
- Protocol type  
- Login attempts  
- Traffic patterns  

These features are used to classify whether activity is **normal or malicious**.
